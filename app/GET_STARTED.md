# 🎯 GET STARTED IN 3 MINUTES

## ⚡ Quick Launch

### Step 1: Create Conda Environment (1 min)
```bash
conda env create -f env.yml
```

### Step 2: Verify Setup (1 min)
```bash
conda activate study_app_env
python verify_install.py
```
This will check everything and tell you if you're ready!

### Step 3: Launch App (instant)
```bash
run_app.bat        # Windows
bash run_app.sh    # Mac/Linux
```

✅ **Done!** The app is now running.

---

## 🎨 The App Has 3 Tabs

### Tab 1: 📄 PDF Viewer
See all PDFs in your collection with file info and content preview

### Tab 2: 🔍 Search Files
Search for keywords across all PDF text content

### Tab 3: 💡 Recommendations
Get recommendations for similar/dissimilar PDFs based on content distance
