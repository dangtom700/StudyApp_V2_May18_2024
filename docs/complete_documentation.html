LearnCraft: Track, Learn, Grow

Complete System Architecture, Pipeline Documentation, and Project Evolution

Introduction

LearnCraft (now expanded into the overarching StudyApp environment) is a revolutionary study companion designed to transform the way you learn and retain information. By combining the power of Natural Language Processing (NLP), semantic search engines, and interactive visual rendering, it provides a comprehensive platform for tracking your study progress and organizing your knowledge.

  • Manage Materials: Store, organize, and access your PDFs in a centralized pipeline.
  • Discover Connections: Utilize powerful semantic search and vector retrieval to uncover hidden similarities between disparate disciplines.
  • Deepen Understanding: Read materials alongside contextually aware AI recommendation engines that promote serendipitous discovery.

System Architecture & Data Pipeline

Python C++ SQLite3 / Chroma DB LangChain / PyMuPDF

The LearnCraft pipeline operates on a powerful dual-language architecture. Python handles data ingestion, semantic NLP, and GUI interactions, while C++ performs highly optimized numerical computation and distance mapping.

1
Data Ingestion (PDF Stack)
Starting with raw PDFs, the system standardizes file names with a hashing algorithm and systematically extracts clean text chunks (~1024 characters) into the SQLite database using src/main.py --extractText.
2
Text Processing & NLP Analysis
The textual corpus is normalized, indexed by stems, and heavily analyzed for frequency. Predefined dictionaries are utilized for --topicTokenize to set authoritative baselines across scientific domains.
3
High-Performance Computation (C++)
The word_tokenizer C++ module computes Euclidean distance mapping, runs TF-IDF vector matrices, and projects relationship distances to enable hyper-accurate document clustering. Features resilient resumption logic to handle large datasets.
4
Semantic Vector Store Insertion
Extracted text chunks bypass legacy text-splitters and are embedded directly into a Chroma Vector Database via src/embed.py, utilizing parallel processing for rapid ingestion and LangChain for local concept routing.
5
Interactive Desktop GUI & LLM Ideation
The user interacts via a PyQt5 desktop app that renders true PDF pages with PyMuPDF. It seamlessly integrates the C++ item matrix calculations for live document recommendations while providing a context pipeline to local Ollama chat servers.

Batch Configuration Flag Dictionary

The orchestrator script (config\main.bat) controls the entire pipeline sequence.

Flag Variable Triggered Command Execution Step
run_extractText python src/main.py --extractText Database Chunk Injection
run_processWordFreq python src/main.py --processWordFreq Stemming & Word Extraction
run_computeRelationalDistance word_tokenizer --computeRelationalDistance Euclidean Distance Mapping
run_mappingItemMatrix word_tokenizer --mappingItemMatrix General Token Mapping
run_labelTopics word_tokenizer --labelTopics Topic Clustering Labeling
