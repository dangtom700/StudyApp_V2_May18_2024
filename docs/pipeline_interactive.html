System Architecture Overview

The LearnCraft pipeline (config\main.bat) operates on a powerful dual-language architecture:

  • Python: Handles data ingestion, PDF text extraction, Natural Language Processing, and LLM integrations.
  • C++: Built as word_tokenizer from src/main.cpp, this module is highly optimized for heavy numerical computation, calculating relational distances, and mapping token matrices.

Follow the timeline beneath to understand how a stack of raw PDF files is systematically transformed into structured, queryable data, eventually feeding into multi-model LLM ideation and content preferencing.

1. Data Ingestion (PDF Stack)

Starting with a fresh stack of PDF files, the system parses, renames, and extracts clean text chunks for further analysis.

  • python src/main.py --renameFile: Standardizes file names utilizing a reliable hashing algorithm.
  • python src/main.py --extractText: Parses PDFs and systematically inserts ~1024 character chunks directly into the database.
  • word_tokenizer --updateDatabaseInformation: The C++ module rapidly scans the resources directory to initialize DB metadata correctly.

2. Text Processing & NLP Analysis

The parsed textual corpus is normalized, indexed by stems, and heavily analyzed for frequency and predefined topics.

  • python src/main.py --processWordFreq: Analyzes raw word frequencies, filters out stop words, and creates precise index tables.
  • python src/main.py --topicTokenize: Tokenizes a predefined dictionary of scientific constraints (e.g., epidemiology, quantum computing) to set authoritative baselines.

3. High-Performance Computation (C++)

Heavy numeric processing is delegated to optimized C++ subroutines, enabling rapid discovery of correlations.

  • word_tokenizer --computeRelationalDistance: Derives the Euclidean norm between differing token frequency vectors.
  • word_tokenizer --computeTFIDF: Runs Term Frequency-Inverse Document Frequency evaluations on the entire DB.
  • word_tokenizer --mappingItemMatrix: Projects and maps relationship matrices accurately across all nodes.
  • word_tokenizer --labelTopics / --expandTopics: Iteratively models, labels, and expands thematic topics via statistical clustering.

4. Contextual Prompting & Reference

With vectorized distances effectively mapped, raw user queries are strictly matched against highly relevant document pieces.

  • python src/main.py --tokenizePrompt: Syntactically assesses the user's immediate search context.
  • word_tokenizer --processPrompt: Isolates and targets specific matching segments inside the pre-computed database for instantaneous retrieval.

5. LLM Ideation & Content Preferencing

Ultimately, referenced context acts as the bedrock for creative and analytic LLM interactive ideation.

  • python src/ideation.py: Fully automates the start of a local Ollama server, piping contextual queries asynchronously across leading LLMs (e.g., Llama3, Mistral, DeepSeek).
  • Outputs and catalogs rich, parallel LLM conversations cleanly into organized markdown/text session records.
